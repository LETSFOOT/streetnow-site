# StreetNow official project website

An English/French, responsive, dependency-free static website for StreetNow, an independent mobile football project developed in Bordeaux, France.

Public website: https://streetnow.fr/

## Hosting

GitHub Pages, deployed from the root of the `main` branch. No backend, database, paid services or build step. `.nojekyll` serves the files directly.

## Content and privacy

The mobile application remains under development. Features implemented in the current build are distinguished from planned progression features. No public download, adoption numbers, company registration or partnership claims are made.

No analytics, external fonts, cookies, tracking or contact form. Contact links open the visitor’s mail application. Existing app legal pages remain on the separate `streetnow-legal` website.

The icon in `assets/` is copied from the existing StreetNow branding asset. The pitch is an original SVG concept illustration, not a screenshot or a live map.

## Domain

Custom domain: `streetnow.fr`, configured after explicit approval. The DNS change is limited to web records and preserves the former FTP destination. Existing mail, Resend and Supabase configurations are preserved. HTTPS is enabled when GitHub Pages has issued the certificate.
